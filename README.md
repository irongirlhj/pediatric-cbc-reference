# 한국 소아 CBC 연령별 참고치 조회 웹앱

환아의 **나이(또는 생년월일)와 성별**을 입력하면, 해당 연령군의 **CBC 참고치**를 즉시 표시하는 웹 애플리케이션입니다.
검사값을 함께 입력하면 참고치 대비 판정(정상 / ↑ / ↓)을 자동으로 표시합니다.

> 2026년 대한임상화학회 진단검사 업무자동화 공모전 출품작

---

## 해결하려는 문제

소아의 CBC 참고치는 성인과 달리 **연령에 따라 크게 변동**하며, 일부 항목은 **성별로도 다릅니다.**
그럼에도 검사실에서는 연령별 참고치 표를 종이나 PDF로 두고 **매번 눈으로 대조**하는 경우가 많아,

- 연령 구간을 잘못 짚는 오류 (특히 `3개월`↔`4개월`, `6세`↔`7세` 같은 구간 경계)
- 성별 구분이 필요한 항목에서 반대 성별 참고치를 적용하는 오류
- 단위 혼동 (논문의 `g/L` ↔ 국내 관례 `g/dL`, `proportion of 1.0` ↔ `%`)
- 조회 자체에 걸리는 반복 시간

이 발생할 수 있습니다. 본 앱은 이 조회 과정을 자동화하여 **시간을 줄이고 오류를 차단**합니다.

---

## 참고치 출처

> **Sung JY, Seo JD, Ko DH, Park MJ, Hwang SM, Oh S, Chun S, Seong MW, Song J, Song SH, Park SS.**
> *Establishment of Pediatric Reference Intervals for Routine Laboratory Tests in Korean Population:
> A Retrospective Multicenter Analysis.*
> **Ann Lab Med. 2021;41(2):155-170.** https://doi.org/10.3343/alm.2021.41.2.155

- **대상**: 국내 4개 대학병원(서울대·서울대분당·서울아산·강남성심) 소아 1,031명, 만 0개월~18세
- **방법**: CLSI EP28-A3c 지침에 따른 간접표본법(indirect sampling)
- **장비**: Sysmex XE-2100
- **라이선스**: Open Access, CC BY-NC 4.0

본 저장소의 [`data/reference.js`](data/reference.js)에 수록된 값은 위 논문 **Table 1**의 값을 그대로 옮긴 것입니다.
논문의 각주(`*`, `†`)도 함께 보존하여 화면에 표시합니다.

**국내 소아를 대상으로 한 다기관 연구**라는 점에서, 타 인종 집단 기반 참고치보다 국내 검사실 현장에 적합합니다.

## 사용 방법

### 실행

별도의 서버나 설치가 필요 없습니다. **`index.html`을 브라우저로 열면 바로 동작합니다.**

```
git clone <이 저장소 주소>
cd pediatric-cbc-reference
# index.html 을 더블클릭하거나 브라우저로 열기
```

로컬 서버로 띄우려면 (선택):

```bash
node server.js     # http://localhost:5173
```

### 조회

1. **나이 입력** — 「나이 직접 입력」(개월/일/세) 또는 「생년월일로 계산」 중 선택
2. **성별 선택** — 필수 (여러 항목이 성별로 참고치가 다름)
3. **참고치 조회** 클릭
4. (선택) 검사값을 입력하면 판정이 자동 표시

## 설계상의 주요 결정

### 1. 연령을 «만 개월» 단위로 처리

원 논문의 연령 구간이 `0-3 mo`, `4-11 mo`, `1-6 yr`, `7-18 yr` 처럼 **개월/년 기준**이므로,
내부적으로 모든 연령을 **만 개월**로 환산하여 반열린구간 `[minM, maxM)`으로 탐색합니다.

```
논문 "0-3 mo"  ->  [0, 4)      논문 "1-6 yr"   ->  [12, 84)
논문 "4-11 mo" ->  [4, 12)     논문 "7-18 yr"  ->  [84, 228)
```

「생년월일로 계산」 모드는 **달력 기준으로 만 개월을 정확히** 계산합니다.
(예: 1월 31일생이 3월 30일에 검사 → 만 **1**개월. 평균일수 나눗셈이면 2개월로 잘못 판정될 수 있는 구간)

「나이 직접 입력」에서 **일(日)** 단위를 쓰면 평균 개월수(30.4375일)로 근사하므로,
구간 경계에 가까울 때는 생년월일 모드를 사용하십시오. (앱 내에도 안내 표시)

### 2. 성별을 필수 입력으로

`WBC(0-3개월)`, `RBC`, `MCV`, `MCH`, `MCHC`, `Hb`, `Hct`, `RDW`, `호산구` 는 성별에 따라 참고치가 다릅니다.
성별 미선택 시 어느 쪽을 택해도 틀릴 수 있으므로, **조회 전 성별 선택을 강제**합니다.

### 3. 단위 이중 표기

원 논문은 SI 단위(`Hb: g/L`, `Hct: proportion of 1.0`, `MCHC: g/L`)를 사용하지만
국내 검사실은 관례 단위(`g/dL`, `%`)를 씁니다.

- **데이터는 논문 원 단위로 저장** (출처 대조 가능성 보존)
- **화면은 «국내 관례» 단위를 기본 표시**, 토글로 «논문 원 단위» 전환 가능

### 4. 값이 없으면 절대 지어내지 않음

참고치가 입력되지 않은 항목은 `—`로 표시하고 상단에 경고를 띄웁니다.
임상 도구에서 **추정값을 참고치처럼 보여주는 것**을 구조적으로 차단합니다.

### 5. 개인정보 비수집

모든 계산은 **브라우저 내에서만** 수행됩니다. 서버 전송·저장·로깅이 없으며 백엔드가 존재하지 않습니다.
환자 식별정보를 입력받지 않습니다.

```
└── README.md
```

데이터와 로직이 분리되어 있어, **다른 참고치로 교체하려면 `data/reference.js`만 수정**하면 됩니다.
각 검사실이 자체 검증한 참고치로 바꿔 쓰는 것을 염두에 둔 구조입니다.

### 데이터 형식

```js
{
  code: "Hb", name: "혈색소",
  unit: "g/L",                                   // 논문 원 단위
  conv: { unit: "g/dL", factor: 0.1, decimals: 1 },  // 관례 단위 환산
  brackets: [
    { minM: 0,  maxM: 4,  sex: "any", low: 97,  high: 134 },
    { minM: 84, maxM: 156, sex: "M",  low: 117, high: 154, note: "†" },
    // sex: "any"(논문의 Both) | "M" | "F"
  ]
}
```

## 검증

연령 구간 경계, 성별 분기, 단위 환산, 판정 로직을 논문 원표와 대조하여 확인했습니다.

| 검증 항목 | 결과 |
|---|---|
| 구간 경계 (`3↔4개월`, `11↔12개월`, `83↔84개월`, `155↔156개월`, `191↔192개월`) | 정확히 전환 |
| 성별 분기 (RBC·MCV·Hb·Hct·MCHC 등) | 남/여 각각 원표와 일치 |
| 단위 환산 (`Hb 138 g/L → 13.8 g/dL`, `Hct 0.40 → 40%`) | 일치 |
| 만 개월 계산 (`1/31생 → 3/30 = 만 1개월`) | 달력 기준 정확 |
| 판정 경계 (하한/상한 포함) | 하한·상한 값은 «정상»으로 판정 |
| 연령 범위 초과 (만 19세 이상) | 조회 차단 + 성인 참고치 안내 |

## 제한사항 및 주의

- 본 도구는 **임상 판단을 보조하는 참고용**이며 진단 목적으로 사용할 수 없습니다.
- 원 논문의 참고치는 **Sysmex XE-2100** 기준입니다. 다른 장비·검사법을 쓰는 검사실은
  **이전(transference) 및 자체 검증 절차**를 거친 뒤 사용해야 합니다.
- **각 검사실이 자체 검증한 참고치가 항상 우선**합니다.
- 적용 연령 범위는 **만 0개월 ~ 18세**입니다. 이를 벗어나면 조회가 차단됩니다.
- 간접표본법(indirect sampling) 기반 참고치이므로, 건강인 직접표본 연구와는 방법론적 차이가 있습니다.
